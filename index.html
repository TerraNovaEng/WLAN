Reading Kernel Interface Metrics

Linux Kernel

On Linux/Android, network interface statistics are exposed directly by the kernel via pseudo-files.

/proc/net/dev

Contains total accumulative bytes received/transmitted per interface (e.g., wlan0, eth0).

/proc/net/arp

Contains the hardware ARP table mapping local IP addresses to physical MAC addresses.

Real Network Inspection & Device Discovery Commands

Standard Linux terminal commands to inspect real hardware interfaces, active socket connections, and discover connected devices on your local subnets.

1. Interface List & IP Addresses 
$ ip -br address show

Displays a concise list of network interfaces (Wi-Fi, Ethernet, loopback), operational status (UP/DOWN), and assigned IPv4/IPv6 addresses.

Alternative: ifconfig or ip addr
2. Discover Local Network Devices 
$ sudo nmap -sn 192.168.1.0/24

Performs a ping sweep on your local subnet to discover active IP addresses, MAC addresses, and vendor names of all connected devices.

Quick ARP Table check: ip neighbor show or arp -a
3. Active Connections & Ports 
$ ss -tunap

Lists active TCP/UDP sockets, establishing which process ID (PID) is communicating with remote IP addresses and ports.

Alternative: netstat -tulnp
4. Persistent Bandwidth Daemon 
$ vnstat -l -i wlan0

vnStat is a console-based network traffic monitor for Linux that logs daily and monthly bandwidth usage without requiring root privileges.

Monthly summary command: vnstat -m

Python Network Diagnostic Scripts

Run these Python scripts locally to inspect real interface bandwidth counters (`psutil`) and active ARP devices.

import time
import psutil

def track_network_usage(interface='wlan0', interval=1):
    print(f"Tracking real usage on {interface}... Press Ctrl+C to stop.\n")
    old_net = psutil.net_io_counters(pernic=True)
    
    if interface not in old_net:
        print(f"Interface '{interface}' not found! Available interfaces: {list(old_net.keys())}")
        return

    while True:
        time.sleep(interval)
        new_net = psutil.net_io_counters(pernic=True)

        bytes_sent = new_net[interface].bytes_sent - old_net[interface].bytes_sent
        bytes_recv = new_net[interface].bytes_recv - old_net[interface].bytes_recv

        # Convert bytes to Megabits per second (Mbps)
        upload_mbps = (bytes_sent * 8) / (interval * 1_000_000)
        download_mbps = (bytes_recv * 8) / (interval * 1_000_000)

        print(f"[{interface}] RX Down: {download_mbps:.2f} Mbps | TX Up: {upload_mbps:.2f} Mbps")
        old_net = new_net

if __name__ == '__main__':
    # Install dependency: pip install psutil
    track_network_usage('wlan0')

Python WebSocket Telemetry Server

Run this script locally to feed real system interface metrics to this UI

Save and execute this script locally. It launches a WebSocket server on ws://localhost:8765 using psutil to broadcast real interface bytes: 

# Prerequisite: pip install psutil websockets
import asyncio
import json
import psutil
import websockets

async def stream_telemetry(websocket):
    print("Dashboard connected!")
    old_net = psutil.net_io_counters(pernic=True)
    
    while True:
        await asyncio.sleep(1)
        new_net = psutil.net_io_counters(pernic=True)
        
        # Select active interface (e.g. wlan0 or eth0)
        iface = 'wlan0' if 'wlan0' in new_net else list(new_net.keys())[0]
        
        bytes_sent = new_net[iface].bytes_sent - old_net[iface].bytes_sent
        bytes_recv = new_net[iface].bytes_recv - old_net[iface].bytes_recv
        
        rx_mbps = (bytes_recv * 8) / 1_000_000
        tx_mbps = (bytes_sent * 8) / 1_000_000
        
        payload = {
            "interface": iface,
            "rx_mbps": round(rx_mbps, 2),
            "tx_mbps": round(tx_mbps, 2)
        }
        
        await websocket.send(json.dumps(payload))
        old_net = new_net

async def main():
    async with websockets.serve(stream_telemetry, "localhost", 8765):
        print("WebSocket Server running on ws://localhost:8765")
        await asyncio.Future()

if __name__ == "__main__":
    asyncio.run(main())

System Architecture & Diagnostics Guide

Real system APIs & Linux diagnostics specification

Browser Network Diagnostic APIs Used:

  • navigator.connection.effectiveType: Queries cellular / Wi-Fi network mode (e.g. 4g, 3g).
  • navigator.connection.downlink: Retrieves browser-level bandwidth estimate in Mbps.
  • navigator.connection.rtt: Obtains estimated round-trip time latency in milliseconds.
  • PerformanceResourceTiming: Used to compute real HTTP request duration and payload rates.
